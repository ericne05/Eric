# Quy chuẩn Viết Mã Nguồn (Coding Convention)

Tài liệu này định nghĩa các quy tắc viết code, cấu trúc mã nguồn và kiểm thử thống nhất trong dự án Eric.

## Nội dung sẽ phát triển:
1. **Lựa chọn Ngôn ngữ & Style Guides**:
   * TypeScript (Frontend / UI / Một số Agents): Cấu hình ESLint & Prettier.
   * Python (Core / Brain / ML / Agents): Tuân thủ PEP 8, sử dụng Black formatter, Ruff linter và Type hints.
2. **Quy tắc đặt tên (Naming Conventions)**: Quy định đặt tên class, function, file, folder rõ ràng.
3. **Quy tắc bình luận & Docstring**: Giữ nguyên docstring và bình luận giải thích thuật toán phức tạp hoặc lý do tại sao dòng code đó tồn tại.
4. **Quy chuẩn Git & Commit Message**: Sử dụng Conventional Commits (ví dụ: `feat: add browser agent navigation tool`, `fix: memory query performance`).
